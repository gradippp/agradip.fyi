# agradip.fyi

Welcome to the deep dive into my personal portfolio! This project was born out of a desire to create a minimal yet visually striking home for my projects, thoughts, and digital experiments.

## The Intention

The main goal was to build a site that feels **alive**. I didn't want a static, boring resume page. I wanted something with:
- **Interactive Elements**: Like the Matrix-inspired pill popup.
- **Atmospheric Visuals**: Using Vanta.js for the dynamic network background.
- **Clean Typography**: Leveraging Geist from Vercel for a modern feel.

## Tech Stack

Building this required a careful selection of tools to balance performance, developer experience, and aesthetics:

- **Next.js 15**: For that sweet server-side rendering and fast routing.
- **Tailwind CSS 4**: For rapid styling with zero runtime overhead.
- **Three.js & Vanta.js**: To handle the background animations.
- **FontAwesome**: For the industry-standard iconography.
